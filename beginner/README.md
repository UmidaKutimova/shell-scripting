# Bash Shell Scripting — Beginner

This section contains beginner-level Bash shell scripting exercises.

The exercises are organized from basic Bash concepts to file handling,
text processing, and error handling.

## Topics

### 01. Basic Shell Scripting

Introduction to Bash scripting, variables, user input, command-line arguments,
arithmetic operations, and string operations.

### 02. Conditional Statements

Working with `if`, `elif`, `else`, comparison operators, and logical conditions.

### 03. Loops

Using `for`, `while`, and `until` loops to repeat commands and process data.

### 04. Functions

Creating and using Bash functions, parameters, return values, and local variables.

### 05. Arrays

Creating arrays, accessing array elements, and looping through arrays.

### 06. Working with Files

Checking files and directories, creating and deleting files and directories,
and reading files line by line.

### 07. Text Data

Working with text files, redirection, CSV data, `cut`, `awk`, and here-documents.

### 08. Errors

Working with exit codes, command substitution, and small Bash projects.
