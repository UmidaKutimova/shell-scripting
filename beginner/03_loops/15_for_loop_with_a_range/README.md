# For Loop With a Range

## 📌 Description

A `for` loop can be used with a **range** to repeat a command for a sequence of numbers.

In this example, the loop goes from `1` to `5` and prints each number.

---

## 📝 Code

```bash
#!/bin/bash

for i in {1..5}; do
  echo "Number: $i"
done
```

---

## 🔍 Code Explanation

### 1. `#!/bin/bash`

```bash
#!/bin/bash
```

This is called a **shebang**.

It tells the operating system that the script should be executed using **Bash**.

* `#!` — identifies the interpreter.
* `/bin/bash` — the location of the Bash program.

---

### 2. `for`

```bash
for
```

`for` starts a **for loop**.

A loop allows us to execute the same block of code multiple times.

In this example, the loop will execute **5 times**.

---

### 3. `i`

```bash
i
```

`i` is the **loop variable**.

It stores the current number during each iteration.

The value of `i` changes as the loop progresses:

```text
1
2
3
4
5
```

`i` is a common variable name for loops, especially when working with numbers.

---

### 4. `in`

```bash
in
```

`in` specifies the values that the loop should process.

Here, the values are generated by:

```bash
{1..5}
```

---

### 5. `{1..5}`

```bash
{1..5}
```

This is called **brace expansion** in Bash.

It generates a sequence of numbers from `1` to `5`.

It is equivalent to:

```text
1 2 3 4 5
```

The `..` means **from the first value to the second value**.

For example:

```bash
{1..3}
```

produces:

```text
1 2 3
```

And:

```bash
{5..10}
```

produces:

```text
5 6 7 8 9 10
```

---

### 6. `;`

```bash
;
```

The semicolon separates commands on the same line.

In this code:

```bash
for i in {1..5}; do
```

the `;` separates the `for` statement from `do`.

The same structure could be written on separate lines:

```bash
for i in {1..5}
do
  echo "Number: $i"
done
```

Both forms work.

---

### 7. `do`

```bash
do
```

`do` marks the beginning of the **loop body**.

The commands between `do` and `done` are executed for every value of `i`.

---

### 8. `echo`

```bash
echo
```

`echo` prints text to the terminal.

In this example:

```bash
echo "Number: $i"
```

prints the current number.

---

### 9. `$i`

```bash
$i
```

The `$` tells Bash to use the **value stored in the variable** `i`.

For example, when:

```text
i=1
```

this:

```bash
echo "Number: $i"
```

becomes:

```text
Number: 1
```

During the next iteration:

```text
i=2
```

so the output becomes:

```text
Number: 2
```

---

### 10. `done`

```bash
done
```

`done` marks the **end of the loop**.

After reaching `done`, Bash goes back to the `for` statement and takes the next number from the range.

When all numbers have been processed, the loop ends.

---

# 🔄 How the Loop Works

The loop processes the numbers one by one.

### First iteration

```text
i = 1
```

Output:

```text
Number: 1
```

### Second iteration

```text
i = 2
```

Output:

```text
Number: 2
```

### Third iteration

```text
i = 3
```

Output:

```text
Number: 3
```

### Fourth iteration

```text
i = 4
```

Output:

```text
Number: 4
```

### Fifth iteration

```text
i = 5
```

Output:

```text
Number: 5
```

There are no more numbers, so the loop finishes.

---

## 💻 Final Output

```text
Number: 1
Number: 2
Number: 3
Number: 4
Number: 5
```

# 🧠 General Syntax

The general structure is:

```bash
for variable in {start..end}; do
  command
done
```

For example:

```bash
for number in {1..10}; do
  echo "Number: $number"
done
```

This prints numbers from `1` through `10`.

---

# 🔢 Different Ranges

### Range from 1 to 3

```bash
for i in {1..3}; do
  echo "$i"
done
```

Output:

```text
1
2
3
```

### Range from 5 to 10

```bash
for i in {5..10}; do
  echo "$i"
done
```

Output:

```text
5
6
7
8
9
10
```

### Reverse range

Bash can also count backwards:

```bash
for i in {5..1}; do
  echo "$i"
done
```

Output:

```text
5
4
3
2
1
```

# 🖥️ How to Run

Create a Bash script:

```bash
touch for_range.sh
```

Open it with Vim:

```bash
vim for_range.sh
```

Add the code:

```bash
#!/bin/bash

for i in {1..5}; do
  echo "Number: $i"
done
```

Save and exit Vim:

```text
Esc
:wq
Enter
```

Make the file executable:

```bash
chmod +x for_range.sh
```

Run the script:

```bash
./for_range.sh
```

# 📚 Key Concepts

| Syntax        | Meaning                              |
| ------------- | ------------------------------------ |
| `#!/bin/bash` | Tells the system to use Bash         |
| `for`         | Starts a for loop                    |
| `i`           | Loop variable                        |
| `in`          | Specifies the values to iterate over |
| `{1..5}`      | Generates numbers from 1 to 5        |
| `..`          | Defines the range                    |
| `;`           | Separates commands on the same line  |
| `do`          | Starts the loop body                 |
| `echo`        | Prints text                          |
| `$i`          | Gets the current value of `i`        |
| `done`        | Ends the loop                        |
